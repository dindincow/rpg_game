# 《小蝦米：異世英雄傳》第一卷 CH03 遊戲開發劇本

版本：V1.0｜小說母稿：`CH03_王宅裡的異鄉人_完整小說.txt`

用途：Claude Code；**以現有專案架構為準**，JavaScript + Phaser 3（若現有專案仍有 Vue 對話 UI 則繼續沿用），不使用 TypeScript。

> **單一故事來源**：小說是正式台詞和因果的準則。此文件只描述互動、演出、狀態和驗收；避免遊戲開發時擅自更換人物初登場章節。選項補充台詞需明確標記。

## 0. 與 CH02 的接續契約

- 進章條件：`ch02_complete === true`。
- 小蝦米26歲，紅色帽T、白T、深藍牛仔褲、黑背包，**不會武功**，左肩挫傷尚未痊癒。
- 手機：`batteryPercent = 6`、`signal = false`；CH03沒有耗電事件，禁止進章重設電量。
- 沈若蘭左腳踝仍扭傷，行走速度降低；老吳應依約送來木材。
- 村長許可：三日暫住，自CH03首個清晨起計算**第一個完整工作日**；本章不自動跳過所有期限。
- CH02 王宅只調查未修繕，初始狀態應是：破門、漏屋頂、床腳歪、院中堵塞、匾額落地。
- 第04章秦無風**正式出場**；第06章顧文淵**正式出場**。本章禁止兩人登場、發言或顯示姓名，禁止直接透露玄機司、青石北倉、蘇記商行軍糧線索。
- 清河村86口、缺糧、水渠乾涸、水車破損、公倉有限，均保持既有設定。

## 1. 核心章節體驗

**主題：** 異鄉人用勞動換取信任，修復「能住的家」，並在修屋過程看見清河村更深的困境。

**主要流程：** 清晨醒來 → 老吳送木 → 鐵匠鋪借工具 → 沈若蘭換藥 → 清理與修補王宅 → 村長檢視 → 小蓮送花 → 夜間警告 → 黑松林伏筆 → CH04。

**本章可玩範圍：** `wang_house_interior`, `wang_house_exterior`, `qinghe_village`, `blacksmith_shop`（鐵匠鋪可用室外互動場景，不必另畫全室內）。

**核心互動：** 調查（E/點擊）、拾取物品、材料分類、修屋小解謎、與NPC對話、開背包、任務追蹤；不新增戰鬥或大規模村莊經營系統。

**設計遊玩時長：** 35–55 分鐘（依探索和對話速度波動，不設強制倒數）。

### S01｜清晨漏雨後

- 從 CH02 已存角色站位、安全存檔點開始。光線切至清晨，地面保留水漬、床歪、掉落匾額。
- 進場顯示章名，讀取小說第一幕。小蝦米醒來後依序調查 `uneven_bed`, `roof_leak`, `broken_door`。
- 不重播第二章雨中跌落事件；用簡短回憶台詞即可。
- 玩家拿出手機的演出只顯示 `6%`、`無服務`（若 UI 可讀文字由疊加介面處理）；沒有扣電。

### S02｜老吳送木

- `wu_delivery` 從院外入口靠近，放下捆木；首次接觸播放小說台詞「小子！還活著嗎？」。
- 物資不是免費刷新的採集點，完成事件後一次性記錄 `woodBundleDelivered=true`。
- **重量限制**：左肩受傷，不允許主角舉起整根大樑；老吳承擔重物搬運，小蝦米做分揀、標記和輕度修補。

### S03｜材料分類

- 三類互動：`usable_wood`, `rotten_wood`, `reusable_tiles`。
- 小解謎不是考試：玩家把可用瓦片/木料放到正確區域，錯誤分類則給小蝦米的幽默提示，可重新放置；無永久失敗。
- 任務結束產生**修屋材料摘要**，數值依實際專案資料表配置，不要在不同章節同時硬編兩套金額和資源。

### S04｜鐵匠韓鐵山初登場

- 初次進入村西鐵匠鋪觸發小說第二幕，透過 `npc_han_tieshan` 對話取得 `hammer_borrowed`, `hoe_borrowed`, `nails_borrowed`, `hinge_borrowed`。
- 道具是**借用**而非永久購得；系統記錄 `borrowedTools`，不得在重複觸發時增殖。
- 韓鐵山認得老吳並聽說小蝦米救了若蘭，但先前並未在 CH02 正式見面。

### S05｜沈若蘭的傷勢

- 觸發在玩家做完一輪清理、左肩提醒出現後；若蘭以減速行走姿態入場。
- 過場鎖玩家移動，表現包紮、換藥。台詞依小說第三幕。
- `shoulderTreated=true` 只改善疼痛與可執行的輕度工作，不等於瞬間痊癒；`shenAnkleSprained=true` 仍保留。
- 沈若蘭的藥草是已預留的尋常藥，不直接扣掉全村救命藥材。

### S06–S09｜修屋主玩法

- **清掃：** 移除三處障礙、恢復可走通道，物件需有對應碰撞更新；不可讓 NPC 困在被移除的障礙上。
- **排水：** 小型坡度解謎，第一次測試水可倒流，提示「提高竹管入口／降低出口」，成功後動畫顯示水流院外舊溝，不能把水直接排到村道。
- **修門：** 消耗記錄為「材料已使用」的舊門鉸與釘子，成功後門碰撞和開關動畫正常；若工具借用狀態缺失，提示回鐵匠鋪。
- **補床：** 換掉危險床腳木塊，成功後新增可休息的互動點，但本章不允許無限睡覺跳天數或刷資源。
- **補屋頂：** 使用先前分類的瓦片，重物由老吳幫忙；畫面以簡短換瓦演出或 CG 表達，不需要玩家高處平台跳躍。
- 修復結果應是「簡樸、乾淨、能居住的舊王宅」，仍有色差與斑駁，**不是豪華新宅**。
- 修屋可以依資源需求調整部分順序，但主線最終需全部通過，避免劇情說門修好了、畫面卻仍掉門板。

### S10｜舊匾額歸位

- 初始 `signFallen=true` 承接 CH02。拾取地上「王宅」牌匾 → 老吳扶牌 → 小蝦米釘回門楣。
- 美術狀態切至 `sign_restored`：木牌仍舊、字可辨認、懸掛端正；`signFallen=false`。

### S11｜村長檢視

- `chen_boan` 到訪，檢視排水、門與物資借用紀錄；以小說第五幕台詞為準。
- 玩家可選擇額外回應（**開發補充台詞**）：
  - A「我先把借用材料記清楚。」→ `chiefTrust +1`。
  - B「老吳伯和韓大哥幫了很多忙。」→ `villageGoodwill +1`。
  - C「我明天想先去看看壞掉的水渠。」→ `canalInterest=true`。
- 三種選擇都收束至「明日辰時到祠堂外幫忙清點」；村長**不**直接授權長住或將王宅轉讓。
- 不在本章真的修好村口水車或全村水渠，也不自動補滿公倉。

### S12｜小蓮與祖母

- 村長離開後，小蓮與祖母到訪，小蓮送小束野花，主角放入陶杯，`flowersOnWindow=true`。
- 保留小蓮和祖母仍然缺糧的世界狀態；花朵是情感回饋，不是大量米糧獎勵。
- 建議特寫 CG02 以小蓮放花、紅帽T小蝦米蹲下為主；也可先只做 Sprite 行為。

### S13｜夜晚的老吳警告

- 玩家在屋內休息後轉夜間環境，老吳從門外傳話。
- 小蝦米不可在此時獨自進入黑松林提前碰見秦無風；森林北側出口夜間暫時不可通行，顯示敘事合理提示。
- 遠景表示幾個持械陌生人與忽明忽滅的火光，**不展示具體身分或人名**。

### S14｜章末伏筆

- 夜間王宅內，主角回到床邊，窗外森林山脊一點冷光閃過；不展示可辨識角色輪廓、不播放秦無風聲音。
- 播放小說「我是不是該先把門再加一根木閂？」台詞，淡出。
- `ch03_complete=true`，儲存 CH04 起始安全點，顯示「第04章 黑松林・命運的相遇」。

| Map | `wang_house_interior_repaired` | **必要** | 同構圖/坐標、床和門修好、地板乾淨、仍保留舊木牆和簡單家具 |

CG 建議 16:9、1920×1080；遊戲地圖則沿用現有 Phaser 座標與尺寸。**CG 本身不烙字幕**，劇情字幕由既有 UI 系統處理；若目前純 Phaser，也由共用 DialogueManager 疊加。

美術重點：修復版王宅仍要像清河村窮困年代的小宅。避免金碧輝煌、鮮豔花海、高級燈籠、大量雕刻與憑空增加的豪宅結構。修復前後地圖建議維持相同外牆輪廓與碰撞錨點。

**天數規則：** 第03章為首個完整工作日，可在完成 S14 時轉至次日清晨作為 CH04 開局；三日暫住尚有後續時間，村長未正式批准永久居住。若現有世界時間已有獨立計數器，請先比對它與「三日之約」事件天數，不要雙重累加。

## 6. QA 驗收標準

1. 必須完成 CH02 才能進入 CH03；首次進入顯示清晨而非 CH02 夜間重播。
2. 手機全程維持6%，不自動充電、不取得訊號；讀檔不重置。
3. 左肩疼痛在工作與對話持續存在，換藥後亦不能單人扛重樑。
4. 沈若蘭仍腳傷未癒，不能用正常奔跑動畫進場。
5. 老吳確實送木、韓鐵山首次出場借工具，重進不重複發物品。
6. 修屋前後視覺狀態一致：門、床、屋頂、院路、匾額更新，碰撞同步。
7. 排水解謎錯誤時可重新測試，不會永久卡住；不讓水流進村道。
8. 修屋成果是簡樸可住的舊宅，不變成豪華官邸。
9. 陳伯安檢視後僅交付明日祠堂清點差事，三日之約仍有效。
10. 小蓮送花只觸發一次，缺糧狀態與86口設定未被擅改。
11. CH03不可出現秦無風、顧文淵的立繪、對話或姓名，不可提前透露玄機司軍糧案件。
12. 章末僅有黑松林火光和冷光伏筆，CH04才正式遇見秦無風。
13. 所有事件重播、過場跳過、存檔載入均無物資重複扣發、軟鎖或 NPC 定位錯亂。
14. 章節完成後 `ch03_complete` 正確持久化並能銜接 CH04。

## 7. 給 Claude Code 的執行指令

1. 先掃描目前專案的實際 `Scene`、地圖、對話、任務、背包、CG、音效與存檔架構。**不要假設一定有 Vue**；若現有專案只有 JS + Phaser，沿用原生 JS UI 系統即可。
2. 確認 CH02 最終存檔旗標與實際王宅素材檔名，列出需相容項目。
3. 先實作 S01–S05 的事件資料與 NPC，再實作修屋互動，再接 S11–S14 劇情。
4. 將小說正式台詞以單一資料來源維護，開發補充台詞另標記，不擅自改寫。
5. 缺少圖片/音樂就先用佔位資源，回報素材清單；不要宣稱尚未繪製的美術已完成。
6. 執行專案現有 build/test；至少檢查：一次性事件、存讀檔、場景進出、過場跳過、碰撞更新、章節銜接。
7. 最後回報已修改檔案、實際完成項目、未完成項目、測試結果與缺少的資源。

**完成體驗：** 玩家第一次在異世界修出能睡的屋子，獲得村民的少量信任，也聽見黑松林的危險正在逼近。下一章才進入秦無風正式登場與第一次命運交會。
