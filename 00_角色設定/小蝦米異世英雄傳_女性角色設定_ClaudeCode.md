# 《小蝦米：異世英雄傳》女性角色設定聖經 v1.0

> **用途**：Claude Code 開發參考、人物對話生成、角色立繪與 CG 需求、劇情事件、好感度與人物關係管理。  
> **專案技術**：Vue 3（JavaScript，不使用 TypeScript）＋ Phaser 3；劇情資料可拆成 JSON／JS。  
> **設定層級**：**【既定】**＝已在共同創作中反覆確認的核心設定；**【建議】**＝為開發補充、尚待定案的細節；**【分支】**＝由玩家選擇決定、不可在全部路線同時視為事實。  
> **特別注意**：部分身高、生日、武功招式及出場章節未正式敲定，下方提供的是**可修改的設計建議，不是既有劇情事實**。

## 0. 世界觀與寫作準則

- **背景【既定】**：架空王朝「大雍」；清河村、黑松林、黑風寨、帝京、寧王府、醉月樓等場景。
- **主角【既定】**：小蝦米／王小明，現代台灣穿越者、程式工程師，主線從求生、清河村與王宅經營，逐步進入江湖、情報與朝局。主角是否「原本是女子、長期女扮男裝」**尚未定案**；目前男女版皆不得被程式或台詞強行鎖死。
- **女性角色原則【既定】**：每位女性都有**獨立目的、技能、職業、盟友、對手及可成立的非戀愛結局**。不能全部寫成圍繞主角爭寵。
- **關係原則**：好感不等於戀愛。分開設計 `trust`（信任）、`bond`（羈絆）、`romance`（戀愛）與 `conflict`（衝突）；重要情節須先滿足劇情旗標。
- **倫理原則**：角色已有承諾或既有關係時（如謝雲姝的婚姻、葉清霜對秦無風的舊情、蘇映雪與顧文淵的舊婚約），應有明確坦誠與關係處理，不以抹黑另一方來方便配對。
- **美術**：CG 可採高完成度日系古風動畫插畫；地圖／行走圖是另一套統一比例的像素素材。CG 原則不烙印台詞和 UI；服裝、髮色、武器跨場景一致。
