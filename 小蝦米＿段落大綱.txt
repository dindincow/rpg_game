《小蝦米：異世英雄傳》
第一部｜完整故事架構 V1.0
20章小段落大綱（候選稿）

故事主軸：現代穿越 → 清河立足 → 三寨紛爭 → 江湖同行 → 京城風雲 → 最終抉擇
預計20章，分為五篇。每章先規劃3～6個小段落，再依劇情需要擴寫。
說明：前8章沿用已建立的故事方向；第9章後為待討論大綱，尚非定稿。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一篇｜異世初醒（第1～4章）
目的：介紹大雍、小蝦米的性格、清河村與秦無風。
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CH01｜最後一行程式碼
1. 台灣深夜加班，小蝦米遇見神祕電腦訊息。
2. 意外穿越至大雍黑松林，發現手機失去訊號。
3. 探索陌生森林，察覺這個世界並不安全。
4. 尋找有人居住的地方，踏上前往清河村的道路。

CH02｜初到清河村
1. 小蝦米初次接觸大雍百姓，因奇特衣著引人注意。
2. 認識老吳、陳伯安，了解清河村的生活。
3. 為取得村民信任，開始協助一些簡單工作。
4. 暫時獲得落腳之處，但還沒有永久居住資格。

CH03｜清河村的困境
1. 發現公倉缺糧、水渠老舊等問題。
2. 認識沈若蘭與村中其他重要人物。
3. 小蝦米利用現代工作經驗協助整理村務。
4. 山林出現不尋常的痕跡，暗示官道並不太平。

CH04｜黑松林・命運的相遇
1. 小蝦米在清河村接觸藥草與基礎採集。
2. 黑松林探索時發現異常，遇見身負重傷的秦無風。
3. 首次雙人戰棋，小蝦米努力救下秦無風。
4. 兩人在危險中建立初步信任。
5. 秦無風返回村中養傷，開啟王宅羈絆事件。

第二篇｜初入江湖（第5～8章）
目的：讓主角結交夥伴，建立清風寨與失蹤糧車主線。
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CH05｜雲山官道・尋藥之行
1. 沈若蘭提出秦無風需要特殊藥材。
2. 小蝦米沿雲山官道尋藥，遭遇山賊。
3. 透過逃脫、道具與地形完成戰鬥。
4. 取得藥材，秦無風傷勢逐漸穩定。
5. 小蝦米與秦無風的信任加深。

CH06｜清河來客・青衫公子
1. 顧文淵來到清河村，與小蝦米相識。
2. 發現糧食運送記錄與村中公倉帳目不符。
3. 顧文淵看見小蝦米與眾不同的思考方式。
4. 兩人決定調查失蹤糧車。
5. 線索指向舊驛道。

CH07｜舊驛道・攔路的武松
1. 小蝦米與顧文淵沿舊驛道尋找糧車線索。
2. 遭武松攔路，小蝦米提出荒唐的百兩賭約。
3. 武松讓三招，小蝦米認輸，雙方因此結識。
4. 得知清風寨的困境與武松的責任。
5. 武松提出三日之約，作為進一步合作的條件。

CH08｜清風寨・三日之約
1. 小蝦米與顧文淵提出清河村、清風寨互助方案。
2. 韓鐵山協助規劃鐵件與寨門修繕。
3. 武松履行承諾，安排兩人見失蹤糧車的押糧人。
4. 證人指認黑風寨旗號，黑風寨成為主要嫌疑。
5. 偽裝成黑風寨的敵人夜襲清風寨，小蝦米與武松並肩守寨。
6. 武松認可小蝦米，糧車線索引向柳溪村。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第三篇｜三寨迷局（第9～12章）
目的：完成隊伍雛形、介紹黑風寨，逐漸揭開突風寨嫁禍陰謀。
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CH09｜柳溪村・水岸疑雲
1. 小蝦米與顧文淵從清風寨返回清河村，整理糧車夫趙成提供的證言與貨物記號，發現失蹤糧食可能經由柳溪村水路轉運，決定前往調查。
2. 沈若蘭因村中藥材短缺，需要前往柳溪村採購藥材，得知小蝦米的調查計畫後主動提出同行，正式加入隊伍。
3. 一行人抵達柳溪村，探索碼頭、藥鋪與商鋪。從船夫、商人及當地居民口中得知，近期有人打著黑風寨旗號劫糧、收取水路通行費，黑風寨的嫌疑逐漸加深。
4. 小蝦米等人夜探下游舊渡口，發現失蹤糧車的貨物記號、刻有黑風寨印記的木箱，以及收貨方寫著「黑風寨」的轉運貨單。多項證據互相吻合，眾人開始相信黑風寨正是劫糧的幕後主使。
5. 調查途中遭到佩戴黑風寨腰牌的蒙面人襲擊。敵人要求交出貨單，雙方爆發碼頭突圍戰。小蝦米一行人成功保住證據，卻更加確信黑風寨與糧車失蹤案有關。
6. 秦無風傷勢改善後循線趕到柳溪村，協助眾人撤離，但仍無法長時間戰鬥。四人在客棧整理證據，決定前往黑風寨當面查證。秦無風正式開始隨隊冒險。

**章節結尾：** 所有證據皆指向黑風寨，小蝦米一行人帶著疑問與戒心，準備前往黑風寨。


CH10｜黑風寨・紅櫻之怒
1. 線索引導小蝦米接觸黑風寨。
2. 秦紅櫻對小蝦米的指控大為不滿。
3. 陸玄策發現劫糧與夜襲事件存在疑點。
4. 鐵震山與小蝦米發生誤會，可能觸發小型戰鬥。
5. 雙方決定暫時停戰，各自查明真相。

CH11｜假旗真賊
1. 顧文淵比對糧車帳冊、斷箭與貨運記號。
2. 小蝦米發現有人故意冒用黑風寨旗幟。
3. 陸玄策提供黑風寨的人員與物資紀錄作為佐證。
4. 查出突風寨石虎與偽裝隊伍有關。
5. 武松與秦紅櫻之間的誤會開始解除。

CH12｜三寨風雲
1. 雷萬山拒絕承認嫁禍與劫糧。
2. 清風寨、黑風寨開始建立臨時合作關係。
3. 小蝦米與同伴阻止突風寨下一次商路襲擊。
4. 戰鬥後取得涉及官商交易的密帳線索。
5. 顧文淵發現事件背後牽涉青石縣城與京城。

本篇提示：三寨嫁禍的謎團逐漸揭開，但不急著在第12章打敗雷萬山；讓官商關係延續至京城篇。

第四篇｜京華夜宴（第13～16章）
目的：讓京城、醉月樓、蕭景衍與蘇映雪進入故事，並推進感情線。
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CH13｜青石縣城・暗帳
1. 小蝦米一行前往青石縣城尋找商號資料。
2. 發現有人利用商行掩護不明貨物流轉。
3. 顧文淵查到貨款最後流向京城。
4. 小蝦米認識新的商人與江湖人物。
5. 眾人決定前往京城調查。

CH14｜京城・初入繁華
1. 小蝦米第一次進入京城，被繁華街市吸引。
2. 透過某場意外，與蕭景衍初次相遇。
3. 小蝦米因不熟悉尊卑規矩，讓蕭景衍留下深刻印象。
4. 介紹京城四大世家的勢力與利益衝突。
5. 顧文淵查知重要證據可能藏於醉月樓。

CH15｜醉月樓・月下風流
1. 小蝦米與同伴想辦法進入醉月樓調查。
2. 柳如煙可在此承擔接應、情報交換的重要戲份。
3. 蘇映雪正式登場，建立她與主線的關聯。
4. 小蝦米無意識的舉動讓蕭景衍越來越在意。
5. 眾人取得部分密帳，但行蹤遭人察覺。

CH16｜王府・不速之客
1. 小蝦米因醉月樓事件，被帶入王府。
2. 蕭景衍開始試探小蝦米的來歷與目的。
3. 小蝦米不經意親近，反而讓王爺先動心。
4. 顧文淵發現密帳指向某個與突風寨合作的勢力。
5. 王府內有人不希望這件事被查下去，危機升級。

本篇提示：蘇映雪的具體身世與定位尚待確認，不擅自定稿。蕭景衍採「小蝦米無意識天然親近 × 王爺先動心、強勢反撩」的關係設定。

第五篇｜江湖歸心（第17～20章）
目的：讓京城陰謀與三寨主線匯合，完成最終戰與人物結局。
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CH17｜京華夜宴・四門風雲
1. 京城四大世家的宴會正式展開。
2. 小蝦米、顧文淵與蕭景衍各自發現不同線索。
3. 蘇映雪與柳如煙的情報線在此交會。
4. 幕後勢力試圖奪回或銷毀密帳。
5. 小蝦米與同伴帶著關鍵證據離開京城。

CH18｜風雨將至
1. 雷萬山得知陰謀可能曝光，決定先發制人。
2. 清河村商路受到威脅，清風寨與黑風寨準備迎戰。
3. 武松、秦紅櫻、陸玄策、鐵震山各自承擔不同任務。
4. 小蝦米調度村莊物資、寨眾與隊伍成員。
5. 秦無風、顧文淵、蕭景衍的個人羈絆進入重要階段。

CH19｜決戰突風寨
1. 小蝦米率領同伴前往突風寨。
2. 石虎率領敵軍阻擋，展開前哨戰。
3. 顧文淵與陸玄策合作破解敵方布陣。
4. 武松、秦紅櫻等人參與決戰。
5. 最終擊敗雷萬山，揭露嫁禍與控制商路的陰謀。

CH20｜異世英雄傳
1. 清河村恢復安定，兩寨與村莊建立新的合作關係。
2. 重要夥伴迎來個人故事的階段性結局。
3. 小蝦米與秦無風、顧文淵、蕭景衍各有專屬羈絆事件。
4. 小蝦米重新思考自己在大雍的歸屬。
5. 依玩家選擇進入不同結局，完成第一部故事。

後續擴寫注意事項
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 全書先以20章候選架構規劃，不為湊篇幅重複劇情。
2. 京城篇目前僅4章，若人物與醉月樓事件不足，可調整章數。
3. 雷萬山從前期就要持續透過商路、山寨與糧貨影響故事，不能只在最終戰突然出現。
4. 蘇映雪保留登場，但其身世、職責與人物關係須再確認。
5. 重要角色不一定全部加入戰鬥隊伍；可用角色事件與立繪登場。
6. 每章確認小段落因果、角色出場、情感進度後，再擴寫成8～12幕小說與遊戲事件。
7. 第9～12章是連結三寨主線與京城篇的重要橋梁，優先確認其邏輯。
