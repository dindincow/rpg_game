# 《小蝦米：異世英雄傳》第一卷 CH02 遊戲開發劇本

版本：V1.0
小說正本：`CH02_飢餓的清河村_完整小說劇本.txt`
用途：Claude Code / Vue 3 + Phaser（JavaScript，**不使用 TypeScript**）

> **單一文本來源規則**：所有正式台詞、人物行為、情緒與故事先後以同版小說正本為準。本文件將小說拆成可執行事件；不得擅自重寫人物台詞、添加主要角色或讓第三章的修屋玩法提前出現。若玩家分支需要新增台詞，先記錄為「開發補充對話」，由編劇回填小說設定。

## 0. 本章邊界與人物連續性

- 角色：小蝦米（王小明）、沈若蘭、老吳、陳伯安、小蓮、祖母、分粥婦人、橫肉惡徒、瘦惡徒。
- **不得出現**：秦無風（第四章才正式登場）、顧文淵（第六章才正式登場）、玄機司及其他機構身分揭露。
- 小蝦米不會武功，林道只以聲東擊西拖延，不可徒手打敗兩名惡徒。
- 開場手機電量承接第一章，劇本基準為 9%；救援消耗 3 個百分點，變 6%。不得在再次觸發或讀檔時重扣。
- 林道救援造成左肩挫傷；第三章沈若蘭可延續處置。沈若蘭腳踝扭傷。
- 村長批准**暫住三日**，不是直接讓小蝦米成為村長、家園領主或取得永久產權。第三章再啟用期限相關玩法。
- 王宅初始破損：門、屋頂、床腳、院中排水；第二章只能檢視，不可完整修繕。
- 遊戲風格：2.5D 像素地圖＋精緻日式動畫風劇情 CG；故事對話用 Vue UI，不把字幕烙在 CG 圖片上。

## 2. 逐場工程分鏡與交互

### S01 黑松林清晨
- 進場：第 1 章在倒木歇完後，玩家從村外森林東出口走進新地圖**村西野林**（`wildwood`，1800×1100，`js/wildwood.js`）；一進野林就顯示第 2 章章名並播開場。野林比黑松林亮、松樹少、雜木與灌木多；林道由西往東，救援空地在中段偏東，東出口通往清河村西村口。
- 地圖連接：村外森林（東出口）⇄ 村西野林 ⇄ 清河村西村口。野林東出口要在第 2 章隨老吳進過村子後才能自由通行。
- 森林環境音，薄霧視差；紅帽T小蝦米行走。
- 旁白／台詞：取小說〈第一幕〉開頭至聽到「放開我！」。
- 線索 `footprints`、`fallen_herbs`（沿林道走過即發現）；兩處都看過後激活 `rescue_vantage`。
- 靠近觀察點後停止玩家移動，過場展示青衣沈若蘭與兩名惡徒。讀取 CG01。
- 防呆：兩處線索都在林道上，順路必經；逃離過遠以任務箭頭提醒，不直接傳送。

### S02 CG01：林道上的呼救
- 構圖：青綠衣沈若蘭坐地，左腳受傷，藥簍翻倒、手握小鋤；惡徒一持棍、一拿藥簍；小蝦米可在遠景樹後或留給返回地圖演出。
- 演出：淡入 300ms；慢推 3–5%；顯示小說惡徒與若蘭對話；淡出 250ms。
- 不可使用動態影像硬編對話。CG 本身無文字；可在 CG 上疊 Vue 對話框。
- 完成後解鎖救援互動。

### S03 救援環境解謎
- 導引：小蝦米思考「不要硬碰硬」，鏡頭依次給出石塊、濃霧樹叢、枯枝、手機圖示。
- 物件：`pickup_stone`、`target_fog_bush`、`phone_alarm`、`slope_branches`。
- 建議操作：
  1. 調查石塊取得劇情道具 `small_stone`。
  2. 對霧林互動「投石」；Phaser tween 石頭軌跡，播放枝葉聲。
  3. 點手機圖示／快捷鍵，選「開啟鬧鐘」；播放 `sfx_phone_alarm` 並觸發假官差台詞。
  4. 與坡上枯枝互動；播放連續腳步假音，進入追擊演出。
- 誤操作：若先接近惡徒，小蝦米吐槽「我又不是練家子」，引導回環境；不進不可恢復的戰鬥。
- 手機 3% 消耗於**救援完成狀態提交時一次性處理**，避免中途存讀檔重複扣除。
- 可配置為物件作用順序，MVP 先固定上述順序；未來可擴充分支解法。

### S04 A1：挨棍與老吳出場（約 7–10 秒）
- 回到 Phaser 地圖，橫肉惡徒跑向主角，主角滑倒；棍影打中肩膀並觸發輕微震屏。
- 老吳從林道入口跑入，用斧背敲樹，播放三次音效；瘦惡徒後退，兩人逃離。
- 角色動作：主角 `run`, `slip`, `hurt`, `sit`; 老吳 `run`, `axe_tap`; 惡徒 `startle`, `retreat`；缺素材則用 tween+方向表情替代。
- 台詞使用小說「你看吧！我就說官差來了！後面還有二十個！」等原句。
- 狀態一次提交：`rescueCompleted=true`、`leftShoulderBruised=true`、`shenAnkleSprained=true`、手機電量 -3；NPC 解鎖。
- 動畫跳過時必須執行相同終局狀態和 NPC 定位。

### S05 林道相識與同行
- 對話：從小說〈第二幕〉三人撿草藥到「這年頭，壞人也不會把壞字寫在臉上」。
- 老吳扶若蘭行走，若蘭較慢；小蝦米可自由走在附近。
- 在 3 個可選區域對話：
  - 若蘭：為何獨自上山採藥？
  - 老吳：清河村多少人？（答：約 86 口）
  - 老吳：青石縣有無官府？（答：有縣衙，但村民難指望及時援助）
- 可選對話不構成卡關條件；永久選擇只影響「已聽過」資訊日誌。
- 禁止玩家攻擊 NPC 或隨意使用手機震退村民。

### S06 A2：黑松林通往清河村（約 5–8 秒）
- 觸發：玩家走到山道出口。
- 演出：鏡頭上移，森林陰影轉成灰瓦村屋、乾涸水渠與水車；音樂從森林緊張氛圍交叉淡入清河村古琴木笛。
- 玩家重新取得移動後可在村口探索。

### S07 清河村探索
- 地圖首次開放範圍：村口、河岸、水渠、荒田、破水車、公倉外；後續可擴大。
- 可調查：`dry_canal`（通水問題）、`abandoned_field`（缺勞力）、`broken_waterwheel`（第三章伏筆）、`granary_queue`（主線推進）。
- 禁止取得無限糧食、修好水車或水渠；這些是後續任務。
- NPC 演出：婦人背竹簍、老人坐著、孩童排隊；低幀數輕微 idle 即可。

### S08 A3+CG02：小蓮的半碗粥
- 觸發：玩家進入公倉前互動範圍。
- Phaser A3（4–6秒）：小蓮端碗靠近祖母，將碗推過去；小蝦米站定。
- 轉 CG02：小女孩面帶強撐笑意、祖母虛弱、小蝦米站在後景，突出一碗稀粥。
- 播放小說〈第三幕〉全段核心對話，**必留**：「小蓮不餓」「剛剛那不是我」「真要是拍戲，誰肯讓孩子餓成這樣？」
- CG 結束後返回地圖補沈若蘭替小蓮問診一段，或在 CG 上續播台詞，兩者擇一保持流暢。
- 不提供「直接把背包大量食物贈送所有人」的選項；此時沒有足夠資源可解決糧荒。

### S09 村長盤問
- 由老吳帶隊進祠堂；婦人報告分糧不足；村長陳伯安起疑問姓名、來歷、路引。
- 原台詞：「救人是一回事，收留又是另一回事」「多收留一個不知來歷的人，便多一張嘴」「承受不起再錯信一次人的代價」。
- 對話立繪表情：村長嚴肅/疲憊；老吳辯護；若蘭擔心；小蝦米從慌張轉理解。

### S10 玩家對話選擇（非分歧主線）
- `ch02_chief_choice` 提供三選一：
  - `work`:「我不白吃白住，可以幫忙工作。」→ `chen_boan` 信任 +1
  - `kind`:「我知道村裡很難，但我真的沒地方去了。」→ `shen_ruolan` 好感 +1
  - `joke`:「放心，我很能幹，也不太挑食！」→ `wu_woodcutter` 好感 +1
- 為保持小說正本連貫，三選一為**開發補充台詞**，後續收束至小說「村長，我不白吃白住」及「先住三日吧」。
- 選項僅可提交一次；返回村長不可重刷好感。
- 需要設計最低信任值保底，玩家無論選哪一項皆可取得暫住權。

### S11 A4 三日之約（約 3–5 秒）
- 村長合上帳簿、起身指向東南方向；小蝦米舉手高興、老吳摸鬍子、沈若蘭輕笑。
- UI Toast：「新據點解鎖：王宅」「跨章節任務：三日之約」。
- 任務旗標：`wangHouseAccess=true`、`threeDayPermitGranted=true`；天數**第三章才開始計數**。

### S12 王宅抵達
- 老吳作為臨時 NPC 引導玩家到王宅；路途中播放小說〈第五幕〉浴室/水井笑話。
- 地圖：王宅門楣「王宅」，缺瓦屋頂、斜門、雜草、破院牆。
- Phaser 門板掉落：`door_fragment` 受互動後位移+旋轉；音效；台詞「現在只剩三面半了吧？」。
- 老吳承諾次日帶木料後沿路離開，不要留在王宅過夜。

### S13 王宅初次調查
- 三個必要互動點：`broken_door`, `roof_hole`, `uneven_bed`；完成 3/3 才觸發入夜過場。
- 調查僅加任務日誌，不耗材料，不自動修繕，不開放製作介面。
- 讓玩家走到乾燥角落、放下背包；切換時間與光影。

### S14 CG03 異世第一夜
- CG：小蝦米紅帽T坐於舊木床旁，手機冷光與月光對照；保留橘紅色短髮和 26 歲成年人外觀。
- 以 Vue 對話框顯示小說〈第五幕〉「王小明，你不會真的回不去了吧？」至「明天先想辦法把這房子弄好」。
- 如果手機內容需可讀 UI，**手機 6% 和無服務文字應由獨立 UI 疊加**，不要烙進 CG。
- 慢推、低音量背景音，讓玩家自己點擊繼續。

### S15 A5 漏雨與床倒（約 6–10 秒）
- 切回 Phaser 室內；雨滴粒子落到主角額頭；主角左右挪；床板旋轉約 8–12°；主角坐倒。
- 受傷肩膀表情、短震屏、滴答和木板聲；不造成永久追加生命值損失。
- 重要結尾：「明天……我一定要先把屋頂修好！」
- 結束：`ch02_complete=true`、寫入存檔、顯示章節完成與 CH03 標題。

- 自由探索時讀檔應回到合適安全點與角色位置；NPC 隊伍跟隨狀態正確恢復。
- Vue UI 在過場期間鎖定移動，過場完解鎖；死亡重試與跳過不得卡在鎖定狀態。

## 6. 小蝦米不能直接學會武功的驗收規則

- 救援時不存在普攻擊敗兩名惡徒的戰鬥通關法。
- 必須先透過地形、聲響分散惡徒注意，老吳才能出現解圍。
- 若玩家按攻擊鍵，給出「我又不會武功，先想辦法吧」提示，不進入常規戰鬥結算。
- 救援是主線事件，玩家選擇謹慎探索不應被懲罰為錯誤；中途失敗可從救援起點重新操作。
